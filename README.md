# FlowPlan 3D

Field app for plumbers, sewer contractors and inspectors: walk a building with your phone, tag units, rooms and fixtures, pin site photos, then draw the sewer, vent, storm and supply runs on a 2D plan or 3D X-ray view.

**Open it:** https://demore88.github.io/Flowplan-3d/

## Install on a phone
- **iPhone (Safari):** Share → *Add to Home Screen*
- **Android (Chrome):** menu → *Install app*

Once opened online one time, it works with no signal. Projects auto-save on the device; use 💾 to save a project file (with photos) and 📂 to load one.

## Files
- `index.html` — the whole app
- `manifest.json`, `sw.js`, `icons/` — install + offline support
- `DESIGN.md` — product design and roadmap

When you change `index.html`, bump `VERSION` at the top of `sw.js`.
